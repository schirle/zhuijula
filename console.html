快速上手

第一次使用，按这 4 步走一遍，站点就能正常用：
① 填网站信息 —— 在下面「站点基础信息」里填网站名称、描述、图标，保存后刷新前台就能看到效果。
② 添加播放源 —— 到「播放设置」添加影视接口。必须添加才能搜索 / 播放（站点不自带播放源），没有接口就去对接你购买或已有的影视接口。
③ 配网盘账号（要用搜索页的「网盘」分类才需要）—— 到「网盘设置」填搜索接口和夸克 / 百度 / UC 的登录信息，访客就能把网盘资源转存后直接播放。
④ 配自动清理定时器 —— 「网盘设置 → 中转副本自动清理」里复制地址，到 cron-job.org 建一个每分钟执行的任务，转存的临时文件就会自动删除。
每改完一块内容，记得点页面最下方的「保存全部配置」。

网站名称会显示在浏览器标签、页面左上角和页脚；网站描述用在搜索结果摘要和页脚，建议一句话写清站点定位。
填图片的网络地址（https:// 开头）。改图标只需改这一行，不用替换任何文件；留空则用默认图标。
图片哪里来：任选一个免费图床（如 ImgURL ↗、PostImages ↗）上传 logo，再复制它给出的直链；也可以填自己的图片地址。
建议用 200×200 以上的正方形图片（png / jpg / ico 都可以）。它会同时作为浏览器标签图标和页面左上角 logo。

网盘搜索设置

这一块负责搜索页的「网盘」分类：先通过网络盘搜索接口找到资源，再用你自己的网盘账号把它转存一份，然后生成站内可直接播放的链接。
下面的账号信息只保存在服务器上，不会展示给访客，可以放心填写。
填你的服务商提供的搜索接口地址（不带 http:// 也可以，系统会自动补）。留空则搜索页不显示「网盘」分类，其它功能不受影响。
填你自己的夸克网盘登录状态信息（Cookie），用于把资源转存到你的网盘。
怎么获取：电脑浏览器登录夸克网盘 → 按 F12 打开开发者工具 → 切到 Network（网络）→ 刷新一下页面 → 随便点一条请求 → 在右侧找到 Cookie 一行，整段复制粘贴到这里。填完可点左边「检测登录态」确认是否有效。
转存的文件要放在夸克网盘的哪个文件夹。这里填的是文件夹对应的目录编号，不是文件夹名字；不确定就留空，会存到根目录，不影响使用。
填你自己百度网盘的登录状态信息（Cookie，需包含 BDUSS 这一段），获取方法与夸克相同：浏览器登录百度网盘 → F12 → Network → 刷新 → 复制任意请求里的 Cookie。不填则百度网盘资源无法转存，其它网盘不受影响。
转存的文件要放在百度网盘的哪个文件夹，直接写文件夹路径（须是你网盘里已存在的文件夹，例如 /影视资源）；留空则存到根目录。
填你自己 UC 网盘的登录状态信息（Cookie），获取方法与夸克相同；不填则 UC 网盘资源无法转存。
转存的文件要放在 UC 网盘的哪个文件夹，同样填目录编号而不是文件夹名字；不确定就留空，会存到根目录。
效果：定时器每跑一次、或你点一次「立即清理」，就会把下面网盘的转存目录整个清空 —— 不管里面的文件存了多久（不再是"等 10 分钟"）。
前提：必须先在上面给对应网盘设置了「目标目录」（夸克 / UC 填目录 ID）。没有设置目录的网盘会被自动跳过，因为那等于清空你网盘的根目录，会把你自己的文件一起删掉 —— 如果你的转存目录就是根目录，请到下面「网盘文件管理」里勾选删除。
百度网盘不支持自动清理（接口限制，删除会被风控拦截），转存到百度的文件请你自己到百度网盘里手动删除。
填 0（默认）= 每次清扫都把目录里的东西全部删掉，一个不剩。
如果你发现「访客播到一半就断」，把这个数改成 10～20：最近这个时间内新增的文件会先留着不删，等下一轮再清。数字越大，你的网盘占用越高，但播放越稳。

网盘文件管理（手动删除）

上面那个「自动清理」只能删系统自己转存进去的临时文件（它靠转存记录认路，所以你从没播过网盘资源时队列就是空的）。
这一块不一样：直接把转存目录里的文件列出来，看清是什么再删 —— 用来清理以前测试留下的、或没被自动清掉的残留。
查看的就是上面填的「目标目录」（夸克 / UC = 目录 ID）；列表只是查看，只有你勾选的项目才会被删，不会碰其它文件。
百度网盘不支持在线管理（接口限制），请到百度网盘 App / 网页里手动删除。
删除后无法恢复；文件夹也会连里面的内容一起删掉，请确认后再操作。

搜索违禁词

访客搜索的词只要命中下面任意一个词，就会被直接拦截：不会去请求影片数据，也不会进入「搜索排行榜」和搜索历史。
匹配规则：不区分大小写、包含即命中（例如填「广告」，搜「广告电影」也会被拦）。留空 = 不拦截任何词。
怎么用
· 一行写一个词，也可以用逗号 / 分号 / 空格分隔，随时可以增删；保存后约 1 分钟生效
· 点「载入推荐词库」= 自动帮你填好一套常用词，填完还能继续修改、删除
· 从别处整理好的词库（一行一个或逗号分隔的文本）可以整段粘贴进来，格式都兼容
小提示
· 建议只填确实不该出现在站内的词；词太短、太常见容易误伤正常搜索
· 如果某个影视剧名里正好含有你填的词，把这个词删掉就行
· 只作用于「搜索关键词」，不会影响网站里的影片数据

搜索排行榜

统计访客都搜了哪些词、各搜了多少次，用来了解站内热门内容。被违禁词拦截的搜索不会计入（词表见「其他设置 → 搜索违禁词」）。
切到总榜 / 日榜 / 周榜 / 月榜查看不同时间范围；「清理旧词」会一并清掉超过 30 天的旧记录。
防刷规则：单字符（如「见」「的」「1」）、纯符号、同一个字重复、少于 4 位的纯数字，都不计入榜单；同一个 IP 短时间内重复搜同一个词，只计第一次。这些是固定的，正常访客碰不到。

搜索防刷与配额

搜索每被请求一次，都会消耗部署平台的一次接口调用额度（免费套餐一般是每天 10 万次）。下面这些数字用来防止有人把额度刷光：超出后前台只是让访客先过一道验证码，正常访客一天的搜索是个位数，填多少都不影响他们。
不确定填多少？照下面挑一套
项目免费套餐建议付费套餐建议
全站每天搜索上限20000100000
同一个 IP 每天搜索上限100300
同一个 IP 每天硬上限200600
每分钟搜索多少次开始验证码612
同一个词每天最多计入榜单100300
懒人公式：全站上限 ≈ 你套餐「每天接口调用额度」的 20%；单 IP 上限 = 免费 100 / 付费 300，硬上限填它的 2 倍。
为什么：免费套餐每天约 10 万次调用（只有 /api 接口算，页面文件不算），全站搜索压到 2 万次，剩下 8 万留给首页、详情、播放等其它接口；付费套餐每月 1000 万次（约每天 33 万次），搜索占三分之一更宽松。
懒得算：直接留空，用系统默认值（40000 / 200 / 400 / 10 / 300）也不会出问题 —— 这些限制只在有人恶意刷的时候才会触发。
超过这个次数后，所有搜索都要先过验证码。按上面表格填即可（约为套餐每日调用额度的 20%，给首页、详情、播放等接口留出余量）；不确定就留空用 40000。
超过后该 IP 需要过验证码。留空用 200。
超过后该 IP 当天直接拒绝搜索（验证码也不放行）。应大于上面的上限；留空用 400。
一个人一分钟内连续搜索超过这个次数，就要过验证码（防脚本连点）。留空用 10。
同一个关键词每天最多给榜单贡献这么多次，避免有人反复刷同一个词占榜。留空用 300。
