追剧插件

在豆瓣电影页面一键「找资源」，直达本站全网播放源。下载即用，找资源快捷又方便。

安装步骤
  1. 1
    下载扩展

    点「下载 Chrome 扩展」获取 zhuiju.crx，或点「安装油猴脚本」获取 zhuiju-douban.user.js（需先装 Tampermonkey 插件）。

  2. 2
    安装扩展

    地址栏打开 chrome://extensions 并开启右上角「开发者模式」：Chrome 扩展直接把 zhuiju.crx 拖入页面；若浏览器拦截，将其重命名为 .zip 解压后点「加载已解压的扩展程序」选择该文件夹即可。

  3. 3
    打开豆瓣即可使用

    访问任意豆瓣电影页面，标题旁会自动出现紫色「找资源」按钮，点击跳转到本站搜索播放源。

功能亮点
一键找资源

豆瓣页面直接唤起本站搜索，省去手动复制片名。

多端通用

支持 Chrome / Edge 等 Chromium 内核浏览器，桌面端即装即用。

常见问题
点击下载后怎么用？

Chrome 扩展为 zhuiju.crx：拖入 chrome://extensions（需开启「开发者模式」）即可；若被拦截，重命名为 .zip 解压后「加载已解压的扩展程序」选择该文件夹。油猴脚本则用 Tampermonkey 一键安装。Chrome 不支持直接双击安装未上架商店的扩展。

按钮在豆瓣页面不显示？

刷新豆瓣页面，确认本扩展已在 chrome://extensions 中处于「已启用」状态，且访问的是 movie.douban.com / www.douban.com。若仍不显示，可移除后重新加载一次。

扩展会读取我的浏览数据吗？

不会。扩展仅在豆瓣页面注入一个跳转按钮，不读取、不上传任何个人信息，可放心使用。
